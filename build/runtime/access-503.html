503 · SERVICE UNAVAILABLE

Service is not ready

The workspace is starting or temporarily unavailable. Initial setup can take several minutes. This page will retry automatically.

If you are trying to sign in

Please leave this page open. If setup does not finish, contact the administrator.

If you administer this service

Set CF_ACCESS_TEAM_DOMAIN and CF_ACCESS_AUD in the service environment, and configure an Access application and policy for this hostname.

Check that the container can reach your team's /cdn-cgi/access/certs endpoint over HTTPS. First-start dependency installation, a starting backend, invalid configuration, or signing keys that could not be refreshed can cause this response.

Review docker compose logs code-server for configuration and key-refresh errors.
