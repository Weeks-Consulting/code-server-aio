503 · SERVICE UNAVAILABLE

Access validation is not ready

This service is waiting for valid Cloudflare Access configuration or trusted signing keys. Access is blocked while authentication cannot be verified.

If you are trying to sign in

Try again shortly. If this page persists, contact the administrator.

If you administer this service

Set CF_ACCESS_TEAM_DOMAIN and CF_ACCESS_AUD in the service environment, and configure an Access application and policy for this hostname.

Check that the container can reach your team's /cdn-cgi/access/certs endpoint over HTTPS. Startup, invalid configuration, or signing keys that could not be refreshed can cause this response.

Review docker compose logs code-server for configuration and key-refresh errors.
